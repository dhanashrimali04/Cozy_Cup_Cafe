☕ Cozy Cup Cafe

Welcome to Cozy Cup Cafe, a front-end cafe website project designed to showcase a cozy and inviting cafe experience. The website features a warm visual theme and a simple, user-friendly interface for visitors to explore the cafe, browse its menu, learn about the cafe, and get in touch.

This project was developed to practice front-end web development and create a multi-page website.

🌟 Features

- Home Page: A welcoming landing page introducing Cozy Cup Cafe.
- About Us Page: Shares the cafe's story and creates a personal connection with visitors.
- Menu Page: Displays cafe food and beverage offerings in an attractive menu-card layout.
- Contact Page: Provides contact information for visitors.
- Responsive Design: Designed to provide a user-friendly browsing experience across different screen sizes.
- Attractive UI: Warm cafe-inspired colors and a clean layout.

🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling, layouts, and visual design
- JavaScript — Interactive front-end functionality

🚀 How to Run the Project

1. Clone this repository:
   
   git clone https://github.com/dhanashrimali04/Cozy_Cup_Cafe.git

2. Open the project folder in Visual Studio Code.

3. Open "index.html" in your browser, or use the Live Server extension in VS Code.

4. Explore the Home, About Us, Menu, and Contact pages.
